# Student Management System

## Description
A menu-driven Python application for managing student records.

## Features
- Add Student
- View Students
- Search by ID
- Search by Name
- Update Student
- Delete Student
- Student Statistics
- Sort Records
- Export to CSV
- JSON Data Storage

## Technologies Used
- Python
- JSON
- CSV

## How to Run

```bash
python main.py
```

## Files

- main.py
- students.json
- student_records.csv
